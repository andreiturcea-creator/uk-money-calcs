**Short answer:** Cookie notice for UK Money Calcs: the site sets no cookies.

Last updated 15 October 2026.

**UK Money Calcs does not set any cookies** and does not use similar technologies such as local storage, tracking pixels or fingerprinting. There is no analytics or advertising code on the site, so there is no cookie banner.

The site is hosted on GitHub Pages, which serves static files and does not set cookies on these pages. If you click through to another site (for example Gumroad, GitHub or a partner), that site may set its own cookies under its own policy once you are there.

If this ever changes, for example if we add analytics or ads, we will list every cookie here and ask for your consent before setting any that are not strictly necessary, as the Privacy and Electronic Communications Regulations (PECR) require. See also our [privacy notice](https://calcs.andreiturcea.com/privacy.html).
